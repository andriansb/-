# Dread — хоррор-мод для Minecraft (Fabric 1.20.1)

Мод превращает тёмные пещеры и ночи в настоящий кошмар. За вами следят...

## Что внутри

- **Сталкер** — высокая бледная фигура со светящимися глазами.
  Пока вы на него **смотрите — он замирает**. Стоит отвернуться — несётся к вам.
  Удар накладывает «Тьму». Если смотреть на него ~6 секунд подряд — он растворяется.
- **Режиссёр страха** — у каждого игрока копится «напряжение»: растёт в темноте, под землёй и ночью,
  падает на свету. Чем выше — тем чаще события:
  шаги за спиной, скрипящие двери и сундуки, шёпот у самого уха, далёкие стоны,
  гаснущие факелы, приступы темноты, а затем и появление Сталкера.
- **Сердцебиение** — когда Сталкер рядом, слышен пульс, который учащается по мере приближения.
- **Оберег** (`dread:ward_charm`) — изгоняет Сталкеров в радиусе 24 блоков и снижает страх.
  Рецепт: золотые слитки сверху/снизу, аметисты слева/справа, **Око Края** в центре.
- **Яйцо призыва Сталкера** — в творческом режиме.

## Команды (права оператора)

| Команда | Действие |
|---|---|
| `/dread spawn` | призвать Сталкера рядом |
| `/dread scare` | случайное страшное событие |
| `/dread tension <0-100>` | задать уровень страха |
| `/dread reload` | перечитать конфиг |

## Конфиг `config/dread.json`

| Поле | По умолчанию | Описание |
|---|---|---|
| `enabled` | `true` | главный выключатель |
| `ambientEvents` | `true` | звуки и «мелкие» события |
| `stalkerSpawns` | `true` | появление Сталкера |
| `snuffTorches` | `true` | гасить факелы рядом с игроком |
| `intensity` | `1.0` | множитель страха (0.1–5.0) |
| `maxStalkersPerPlayer` | `1` | лимит Сталкеров |
| `stalkerLifetimeSeconds` | `180` | время жизни Сталкера |
| `banishStareSeconds` | `6` | сколько нужно смотреть, чтобы прогнать |

## Сборка

Нужны JDK 17 и Gradle 8.5+.

```bash
gradle wrapper --gradle-version 8.5   # один раз, создаст gradlew
./gradlew build                        # jar будет в build/libs/
./gradlew runClient                    # запуск Minecraft для теста
```

## GitHub Actions

- `.github/workflows/build.yml` — сборка на каждый push / pull request, jar выкладывается как артефакт.
- `.github/workflows/release.yml` — при теге `v*` (например `git tag v1.0.0 && git push --tags`)
  собирает мод и создаёт GitHub Release с jar.

Wrapper не нужен: workflow сам ставит Gradle 8.5.
